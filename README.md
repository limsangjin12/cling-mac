# Cling for macOS

Cling is a menu bar window manager for macOS. It moves and resizes the focused
window with menu commands, keyboard shortcuts, drag zones, and custom layouts.

This repository is for public downloads and release notes. The app source code
is maintained separately.

## Install

```bash
brew tap limsangjin12/apps
brew install --cask cling-mac
```

After launch, allow Cling in System Settings > Privacy & Security >
Accessibility. Cling uses Accessibility only when you choose a window command.

## Direct Download

Download the latest notarized ZIP from
[Releases](https://github.com/limsangjin12/cling-mac/releases).

## Privacy

Cling does not use accounts, ads, analytics, tracking, subscriptions, or a Jin
Factory server. Settings are stored locally. Optional iCloud settings sync, if
enabled in the app, uses the user's private iCloud key-value store.
